# esp_lcd_st7703

Arduino-library adaptation of Waveshare's ST7703 MIPI-DSI component, pinned to commit `d081959d3841e0b370c2957c122bf8604ab42bc8` and component version 3.0.1.

Source: <https://github.com/waveshareteam/Waveshare-ESP32-components/tree/d081959d3841e0b370c2957c122bf8604ab42bc8/display/lcd/esp_lcd_st7703>

The initialization bytes and 720×720 timing are panel data. The implementation is adapted to expose a small Arduino-compatible factory while retaining the ESP-IDF MIPI-DPI scanout path. Content was rephrased for compliance with licensing restrictions.
