# esp_lcd_st77916

Minimal Arduino-compatible `esp_lcd` ST77916 QSPI panel driver for this project.

Source: Waveshare's `ESP32-S3-Touch-LCD-1.85C` example, whose driver carries
Espressif's Apache-2.0 header. Inactive historical initialization tables were
removed; the maintained V2 initialization sequence is retained.

https://github.com/waveshareteam/ESP32-S3-Touch-LCD-1.85C
